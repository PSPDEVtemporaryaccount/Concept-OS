# Concept OS
### The Ultimate Device Design Studio

**Concept OS** est un atelier de conception numérique consacré aux appareils électroniques et à leurs systèmes d'exploitation. Le projet n'est pas un jeu : il rassemble une bibliothèque de références, un studio de visualisation et un concepteur d'interfaces.

> Imagine the device. Design its world.

## Web Preview — Beta 0.1.0

Cette première version web responsive propose :
- Accueil et navigation entre les espaces de travail.
- Bibliothèque de huit appareils de référence avec recherche et filtres.
- Aperçu interactif de maquettes d'appareils, manipulable à la souris ou au toucher.
- OS Designer : nom du système, fonds d'écran, forme et taille des icônes.
- Enregistrement de concepts dans la session du navigateur.

### Limites de cette preview
Les appareils sont actuellement des maquettes CSS : **ce ne sont pas encore des modèles 3D photoréalistes**. Les créations sont conservées uniquement pendant la session du navigateur et ne sont pas encore synchronisées ni sauvegardées durablement. Ces fonctions seront développées dans les prochaines versions.

## Vision
- Smartphones, tablettes, ordinateurs, consoles, handheld PC, montres et casques.
- Modèles 3D détaillés avec matériaux réalistes, proportions fidèles, éclairage et inspection.
- Création d'OS : écran d'accueil, icônes, widgets, notifications, thèmes et animations.
- Projets personnalisables, sauvegardes et exports.

## Développement
La priorité est la validation de l'expérience Web. L'application Android et son APK ne seront préparés qu'après validation de cette preview. Une publication sur F-Droid est envisagée ensuite.

## Déploiement
Le site est déployé automatiquement avec GitHub Pages via GitHub Actions après activation du workflow.
